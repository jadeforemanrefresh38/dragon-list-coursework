# Dragon List

**Выполнил:** Смирнов Виктор Александрович

**Группа:** ИС11-24-2

Курсовая работа по теме «Заметки с метками». Проект подготовлен для разработки в OpenIDE с системой сборки Maven и целевой версией Java 17.

Веб-приложение на Java с интерфейсом предыдущего Dragon List. Рабочий адрес: https://dragon-list.lol. Старое приложение остановлено, его контейнер, данные и копии сохранены для отката. Его учётные записи автоматически в новую БД не переносились.

Поддерживаются заметки, Markdown, автосохранение, задачи, черновики, корзина и восстановление, поиск, метки с цветами, закрепление, изменение порядка и массовые операции. Есть профиль, аватар, загрузка изображений, смена пароля, светлая и тёмная темы. Интеллект-карты исключены по заданию. Для каждого аккаунта создаются метки «Важное», «Идеи», «Учеба», «Личное».

## Стек и структура

Сервер: Java 17, Spring Boot 3.5.16, Spring Security, Spring MVC, JPA и JdbcTemplate, Flyway. Версии Java-библиотек согласованы BOM Spring Boot. В продакшене — PostgreSQL 16; локально — H2. Интерфейс: React 18, JavaScript и CSS. Python используется для проверок, серверная логика приложения написана на Java.

SQL использует параметры; пользовательский ввод не вставляется в текст команды. Дублирующие старые HTML-формы заметок и общий монолитный WorkspaceService удалены.

## Открытие и запуск в OpenIDE

1. Склонируйте репозиторий и в OpenIDE выберите **File → Open**, затем корневой `pom.xml` и открытие как проекта.
2. Дождитесь импорта Maven и загрузки зависимостей. Если импорт не запустился автоматически, выберите **Add as Maven Project** для `pom.xml`.
3. В **File → Project Structure → Project SDK** выберите установленную JDK 17 или новее. Если SDK с именем `17` не найден, укажите свою установленную JDK; уровень языка и целевая версия сборки остаются Java 17.
4. Выберите конфигурацию **Dragon List** и нажмите **Run**. После запуска приложение доступно по адресу `http://127.0.0.1:8080`. Для проверки и сборки используйте конфигурацию **Maven verify**.

В репозиторий включены общие настройки IDE. Рабочее состояние редактора, пути к локальным SDK и генерируемые Maven-файлы модулей не сохраняются. Если порт 8080 уже занят другим локальным запуском, сначала остановите его.

## Запуск из терминала

Нужны JDK 17+ и Maven 3.6.3+:

```sh
mvn clean verify
java -jar target/dragon-list-1.0.0.jar
```

Откройте http://127.0.0.1:8080 и зарегистрируйтесь. Данные H2 сохраняются в `data/`; готовых аккаунтов нет. Для сборки интерфейса нужны Node.js 24 и pnpm 11.25.0: выполните `pnpm install --frozen-lockfile`, затем `pnpm build` в `frontend/` и пересоберите JAR. Node.js на VPS не требуется.

## Защита и развёртывание

Рабочая схема: внешний Caddy с HTTPS → Coraza с OWASP CRS → Java → PostgreSQL. Порты приложения и БД не публикуются. Java и WAF работают без root, с файловой системой только для чтения, без Linux capabilities и с ограничениями ресурсов. Для миграций и приложения используются разные роли БД. Секреты создаются на VPS и не включаются в репозиторий.

Реализованы BCrypt, CSRF, CSP, Secure/HttpOnly/SameSite-cookie, отзыв других сессий при смене пароля, ограничения входа по адресу и логину, квоты данных, пагинация и перекодирование изображений. WAF блокирует тестовые SQLi, XSS, обход путей и команды в параметрах запроса. Узкие исключения разрешают код в тексте заметок; основная защита SQL остаётся в Java и правах БД.

Ежедневные копии PostgreSQL хранятся 14 дней вне контейнера приложения. Восстановление проверено в отдельную БД. Развёртывание, обслуживание и откат описаны в [инструкции](docs/security/DEPLOYMENT.md), источники GitHub — в [SOURCES.md](docs/security/SOURCES.md), результаты — в [VERIFICATION.md](docs/security/VERIFICATION.md).

Debian 11 совместим с контейнерным запуском, но обычная LTS-поддержка закончилась 31 августа 2026 года. Общий VPS с привилегированным VPN-контейнером остаётся риском. Приоритет — отдельный VPS с поддерживаемой ОС и внешние копии. ОС, Docker, SSH и настройки VPN в рамках переноса не обновлялись.

## Проверки

Всего **57 различных автоматизированных тестов**:

- 8 Java-тестов: `mvn verify`.
- 41 Python HTTP-тест: `python3 tests/python/run_tests.py`.
- 8 Python-проверок контейнеров и БД: `python3 tests/ops/test_deployment.py` на собственном VPS.

HTTP-набор запускается только против вашего развёртывания, создаёт отдельные временные аккаунты и проверяет функции сайта и защиту. Инструкция: [tests/python/README.md](tests/python/README.md). Все 41 HTTP-тест прошли через PostgreSQL/WAF и повторно через публичный HTTPS; 8 серверных и 8 Java-тестов также прошли. CI запускает Java и HTTP-тесты на H2, четыре проверки WAF там пропускаются: полноценный WAF проверен на VPS.

## Учебные материалы

Основной текст курсовой находится в `docs/`. Отдельный трёхстраничный план защиты с данными студента расположен в `submission/security-plan/План_защиты_Dragon_List_Смирнов.docx`. Учебные документы не включаются в JAR и образы; на VPS передавался только разрешённый набор файлов развёртывания. Исходный документ пользователя не изменялся.

Ограничения: нет восстановления забытого пароля и двухфакторного входа. Контейнеры и WAF не заменяют обновление хоста и защиту от объёмных DDoS-атак. Новая БД не содержит старые аккаунты; старые данные доступны для отдельного согласованного переноса.
