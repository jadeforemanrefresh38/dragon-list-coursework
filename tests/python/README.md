# HTTP-проверки

Python 3.9+, только стандартная библиотека. Запускайте набор на собственном развёртывании: он создаёт временные аккаунты и данные, отправляет тестовые вредоносные строки и проверяет ограничение входа.

```sh
DRAGON_BASE_URL=https://dragon-list.lol DRAGON_EXPECT_WAF=1 python3 tests/python/run_tests.py
```

Для локального приложения достаточно `python3 tests/python/run_tests.py`: адрес по умолчанию — `http://127.0.0.1:8080`, четыре проверки WAF пропускаются. В PowerShell задайте переменные через `$env:DRAGON_BASE_URL='...'`.

Набор содержит 15 функциональных и 26 защитных тестов. Проверяются заметки, метки, поиск, пагинация, задачи, черновики, корзина, массовые операции, изображения, профиль, смена пароля и отзыв других сессий. Проверки безопасности охватывают доступ к чужим объектам, CSRF, ограничения файлов и полей, заголовки, cookie и блокировки WAF. SQL и HTML в тексте заметки должны сохраняться буквально.

Отчёт: `.work/reports/python-http.xml`. Манифест созданных аккаунтов: `.work/reports/test-accounts.jsonl`. В `tearDown` удаляются созданные заметки и метки. Сами аккаунты остаются до отдельной административной очистки: удаляйте только точные логины из манифеста в соответствующей БД, с проверкой адреса развёртывания. Общий пароль `TestPass123!` предназначен только для этих временных аккаунтов. Не оставляйте их в открытом рабочем приложении.

`DRAGON_SSH_TUNNEL=1` разрешает тестовому клиенту передавать Secure-cookie по HTTP **только на явно заданный частный адрес стенда** и добавляет `X-Forwarded-Proto: https`. Это режим закрытого стенда на сервере или SSH-туннеля, не обычный способ публичного тестирования. На публичном адресе используйте настоящий HTTPS без этого флага. Режим не меняет приложение или настройки браузера.

Серверные проверки отделены: `python3 tests/ops/test_deployment.py` запускается на VPS с административным доступом к Docker. Они читают конфигурацию, проверяют запрет DDL в транзакции с откатом и сверяют ранее сохранённый снимок VPN. Учебный план защиты для их работы не нужен.
