Всего в исходниках **57 различных автоматизированных тестов**: 8 Java + 41 HTTP + 8 серверных. Повторные прогоны не считаются новыми тестами. Результаты являются проверкой выбранных сценариев, а не обещанием отсутствия любых уязвимостей или независимым пентестом.

Первый прогон выявил ложную блокировку SQL-примера в содержимом заметки. После узкого исключения для JSON-полей заметки повторный набор прошёл целиком. Проверки атак в поиске, форме и параметрах продолжают блокироваться. Через браузер дополнительно проверены вход, загрузка списка, открытие заметки, Markdown и вывод `<script>` как текста, а также выход.

В публичном прогоне проверены Secure/HttpOnly/SameSite-cookie, HSTS и CSP, запрет запросов без корректного CSRF, чтения и изменения чужих объектов, атомарность массовой операции, отзыв других сессий после смены пароля и ограничение попыток входа. Квоты больших объёмов данных проверяются в коде, HTTP-набор не заполняет рабочую БД тысячами заметок и не является нагрузочным тестированием.

Тестовые аккаунты из обоих HTTP-прогонов удалены по точным логинам из манифестов. Временная учётная запись браузерной проверки также удалена. Новое приложение не импортировало старые аккаунты; старые данные сохранены в старом развёртывании.

Старое приложение `dragon-list-app-1` остановлено без удаления контейнера, томов, образа и данных. Внешний `dragon-list-web-1` продолжает обслуживать TLS и направляет запросы в `dragon-java-waf-1`. Старый таймер копий отключён, поскольку его сценарий автоматически запускал старое приложение. Новый таймер копий включён отдельно. Файлы учебного плана не передавались на VPS.

Оставшиеся риски: Debian 11 за пределами обычной LTS, старый Docker/ядро, общий хост с привилегированным VPN, административный SSH-доступ, локальные копии на том же VPS. Эти вопросы не устранены настройкой WAF. Настройки SSH, VPN, глобального Docker и firewall не менялись; приоритет — отдельный поддерживаемый хост и внешние копии.
